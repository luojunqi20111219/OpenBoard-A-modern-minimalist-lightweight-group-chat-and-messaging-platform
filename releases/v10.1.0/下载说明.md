## 安装步骤

1. 解压压缩包（Windows 可用 7-Zip / WinRAR，手机可用 ZArchiver）
2. 把两个 APK 传到手机
3. **直接覆盖安装**，不需要先卸载（签名一致，聊天记录会保留）
4. 普通用户只装 `Client`；管理员两个都装

> 如果系统提示"未知来源"，在设置里允许该文件管理器安装应用即可。

## 更新后你会看到什么变化

打开聊天端，如果某个账号卡在"需要重置密码"，登录页会多出一个
**「重置为默认密码」按钮**：

```
点按钮 → 二次确认 → 重置为 12345678 → 自动登录
       → 强制全屏改密（出不去）→ 设置自己的新密码 → 正常进入
```

**如果连的是普通（Python/FastAPI）服务端，这个按钮不会出现** ——
客户端会自动探测服务端类型，普通版上界面和以前完全一样。

## 服务端部署（如果你自己在维护服务端）

v10.1.0 需要给 `users` 表加一列，**必须执行迁移**：

```bash
npx wrangler d1 execute openboard-db --remote \
  --command "ALTER TABLE users ADD COLUMN must_change_password INTEGER NOT NULL DEFAULT 0"
```

或者在管理端 App 里点「应用迁移」。

**忘了迁移也不会崩** —— 重置密码照样能用，只是"强制改密"不生效，
接口会返回 `migration_required: true` 如实告知。这是故意设计的降级路径：
"灌完 schema、还没点应用迁移"是部署流程里一个完全正常的中间状态。

| 哈希类型 | 账号数 | 其中可自助重置 |
